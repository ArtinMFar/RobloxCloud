RobloxCloud

Roblox, on a cloud GPU

RobloxCloud rents a GPU from Google Colab, runs Roblox on it with Cordial and streams it to this page. Play with a keyboard and mouse or with touch controls.

  1. 0

    Connect GitHub

    One time. GitHub Actions starts and stops the Colab VM.

    Make a fine-grained token for this repository with these repository permissions: Actions read and write, Secrets read and write, Commit statuses read. (A classic token with the repo scope also works.) It stays in this browser.

  2. 1

    Sign in with Google

    The Colab CLI's sign-in. Colab bills GPU time to this account.

    This opens the same Google page as the colab command-line tool. Approve it, then copy the authorization code Google shows and paste it here.

  3. 2

    Pick a GPU

    Roblox renders on it with NVIDIA's Vulkan driver.

  4. ·

Roblox may ban accounts that use third-party clients such as Cordial, so play on an account you can afford to lose. Colab's free tier does not allow remote desktops; a paid plan avoids that rule. Source
